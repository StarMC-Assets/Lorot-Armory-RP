# Lorot Armory ResourcePack

## Overview
This resource pack adds a variety of equipment models from Star Wars during the Clone Wars. Custom items are obtained by renaming on the anvil.

## Compatibility
MC Version: 1.21.11.

This resourcepack requires mods:
- [Variants CIT](https://modrinth.com/mod/variants-cit) for custom armor;
- [Glowtone](https://modrinth.com/mod/glowtone) for emissive effect.

## Items List
To get custom items, you need to rename certain items. You can find the full list in items.txt.
